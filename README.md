# ScientificCalculator
This software simulates a scentific calculator on a website with all useful function for both everyday life and complex mathematical tasks.
If you are preparing this guide for a friend or a colleague to help them run the C++ Scientific Calculator on their own machine, here is a professional, step-by-step manual you can give them.
🚀 User Guide: Scientific Calculator (C++ Edition)This guide will walk you through setting up and running the Scientific Calculator directly from your Command Prompt (CMD).
Phase 1: Setting up the CompilerSince C++ is a compiled language, your computer needs a "translator" (compiler) to turn the code into an application.
Download the Toolchain: Go to MSYS2.org and download the installer.
Installation: Run the setup. When the terminal pops up, type the following command to install the C++ tools:pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchainConfigure Environment Variables: * Search for "Edit the system environment variables" in your Windows Start menu.Click Environment Variables > Select Path > Click Edit > New.Paste the path to your compiler's bin folder (usually C:\msys64\ucrt64\bin).Restart your computer or CMD.
Phase 2: Compiling the ProgramOnce the compiler is ready, follow these steps to build your app:Place the File: Save the provided code as main.cpp in a folder (e.g., a folder on your Desktop named CalcProject).Open CMD: Press Win + R, type cmd, and hit Enter.Navigate: Type the following to enter your project folder:cd Desktop\CalcProjectBuild the App: Run this command:g++ main.cpp -o ScientificCalcThis creates a file named ScientificCalc.exe in your folder.
Phase 3: Running and Using the CalculatorTo start the program, type ScientificCalc in the CMD.⌨️ Interaction GuideThe calculator uses a Command-First logic. 
Type the command, hit Enter, then provide the numbers.CommandActionExampleNumbersDirectly type a number10 [Enter] Sets result to 10Operators+, -, *, /+ [Enter] 5 [Enter] adds 5Trigsin, cos, tansin [Enter] 90 [Enter]Advancedroot (n-th root)root [Enter] 8 [Enter] 3 [Enter] (result: 2)Basesbasebase [Enter] 10 [Enter] (shows Hex/Bin)SettingsmodeSwitches between DEGREE and RADIANControlmenu or clearShows help or resets to 0ExitexitCloses the application.
⚠️ Pro Tips for the User:Case Sensitivity: The program is user-friendly; you can type SIN, sin, or Sin and it will understand.Precision: Results are shown with 6 decimal places for scientific accuracy.Safety: The program includes "Division by Zero" protection to prevent crashes.
